# Front-end - Planejamento

Esta pasta concentra os artefatos mais úteis para implementar a interface da aplicação.

## Arquivos

- `CLAUDE_FRONTEND.md`: contexto e orientações para desenvolvimento do front-end.
- `teste-verzel-casos-de-uso-v1.md`: diagrama de casos de uso, útil para organizar telas e navegação.
- `teste-verzel-casos-de-uso-textual-v1.md`: descrição dos fluxos, regras e alternativas esperadas.
- `teste-verzel-integracao-tmdb-v1.md`: referência para consumir os dados de catálogo expostos pelo back-end.

## Foco

- Login por papel.
- Fluxo do Organizador.
- Fluxo do Cliente.
- Tela da Portaria.
- Exibição de QR Code.
- Leitura de QR Code pela câmera e alternativa por código manual.
